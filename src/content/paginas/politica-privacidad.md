## Datos que se recogen

Este sitio web **no recoge datos personales de forma automática**.

Si utilizas el formulario de contacto o envías un correo electrónico, únicamente se procesarán los datos que tú mismo facilites (nombre y correo) con el fin exclusivo de responder a tu mensaje.

El tratamiento se realiza con base en tu consentimiento explícito al enviar el formulario o el correo.

Los datos se conservan el tiempo necesario para gestionar tu consulta y no se ceden a terceros.
